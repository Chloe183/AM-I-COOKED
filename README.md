# AM I COOKED? — Nyan Cat Edition

A static, pixel-art crisis quiz. No dependencies, build step, or server required.

## Files
- `index.html` — HTML page
- `style.css` — visual styles and animations
- `script.js` — interactive logic

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` into the **root** of the repository (not inside an extra folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for deployment, then open the Pages URL shown in Settings → Pages.

You can also open `index.html` locally to test the website.
